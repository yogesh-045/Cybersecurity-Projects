# Investigation Summary

## Incident Type

Phishing Email

## Severity

High

## Findings

- Fake Microsoft domain detected.
- Urgent language used.
- Suspicious login URL identified.
- Social engineering observed.
- Credential harvesting attempt.

## Conclusion

The email was classified as a phishing attempt.

## Recommended Actions

- Block sender.
- Block domain.
- Notify users.
- Reset credentials if clicked.
